## Project Overview

The objective of the project was to develop an autonomous vehicle capable of:

- Following a road-like trajectory using onboard vision.
- Detecting and classifying traffic signs using a YOLO-based perception system.
- Modifying its behavior according to the detected traffic signs.
- Navigating an urban-scale prototype environment.

The system combines classical computer vision techniques for lane following with deep-learning-based traffic sign detection.

## Repository Structure

### yolo_msg

Custom ROS 2 message definitions used to exchange object detection results generated by the perception pipeline.

### yolo_signals

Traffic sign detection package based on YOLOv8.

#### signsDetector.py

- Receives camera images.
- Performs traffic sign detection using a trained YOLO model.
- Publishes detected traffic sign information.
- Publishes annotated images for visualization and debugging.

### autonomous_navigation

Lane-following and navigation package.

#### image_resizer.py

Preprocesses incoming camera images by resizing and rotating frames before they are consumed by the perception modules.

#### lineFollower.py

Implements lane detection using classical computer vision techniques and publishes a steering reference based on the detected road geometry.

#### controller.py

High-level navigation controller responsible for:

- Following lane references.
- Reacting to traffic light detections.
- Handling intersections.
- Executing traffic-sign-dependent behaviors.
- Publishing velocity commands to the robot.
